# 噪声监测数据站 · 六年级第5课

完整课堂应用《连续变化的数据》（信息科技六年级《过程与控制》第二单元“数据运算有逻辑”第5课）。延续第4课“校园系统探索站”的结构：学生端、教师大屏、本地数据库（Node 内置 SQLite）、六年级名单与可搬迁资源；不需要实时AI、外网素材或3D运行库。

## 上课入口

双击 `启动课堂.command`（需要 Node.js 22.13 或更新版本），或在本目录运行 `npm start`。

- 教师大屏：`http://localhost:8796/teacher`，也可用教师电脑自己的局域网 IP 打开 `http://教师电脑IP:8796/teacher`。免密码。
- 学生入口：同一局域网访问终端显示的 `http://教师电脑IP:8796/`（启动时自动列出，不写死IP）。
- 端口 8796，与第4课的 8794 不冲突，两课可以同时开着。如需改端口：`PORT=8800 npm start`。

教师页、教师测试模式 `/test`、答案和班级数据接口默认只接受教师电脑自身地址的请求，学生设备打开会得到 403；学生页面不出现教师或测试入口。若教师要用另一台设备（如平板）看大屏，按部署需要设置允许地址：`TEACHER_ALLOW=192.168.1.23 npm start`（多个用逗号隔开，可写网段如 `192.168.1.0/24`；网段越大，学生越可能进入教师页，请按实际教室网络选择）。

## 学生端（沉浸版，2026-10-10 重做）：今晚，你是小区噪声巡查员

学生不再面对表单式页面，而是扮演“小区噪声巡查员”（Kenney CC0 卡通角色，可点 HUD 头像换男/女角色），和向导小递一起走在**夜晚小区地图**上（与《导入》页同一画风）。五关是小区里的五个地点，第六个地点“巡查报告站”是20题考核。

**焦点引导（解决“学生不知道点哪里”）**：任何时刻只有一个发光的主要操作（金色按钮 + 脉动光圈），旁边贴一句话提示和指示小手；其余按钮都是低调的次要样式或暂时隐藏。底部小递气泡给完整一句说明和刚才操作的反馈。右上角 **?** 按钮：再给一级提示（观察 → 思路 → 具体帮助，计入提示次数）并用聚光灯压暗其他区域几秒，照亮当前该点的地方。喇叭按钮开关音效（默认关）。“减少动态效果”系统设置下，所有动画关闭，功能不变。

每个地点内是三步：**想一想**（情境 + 一句问题 + 2—3张大选项卡，选完自动进入实验）→ **做实验**（场景里只亮出当前要操作的控件，结果自动保存，两枚“证据徽章”点亮后出现“说清楚 →”）→ **说清楚**（一张卡一个问题，选完自动翻下一张；最后一张是“检验我的解释”）。检验不通过时，对不上的卡片标红并写明原因，引导逐张修改后再检验；通过后角色欢呼、+10★ 并给一句本站收获，回到地图，下一站亮起。

| 地点（关卡） | 做实验（结果自动保存） | 说清楚（提交后判定） |
|---|---|---|
| 1 广场监测器（数据在哪里流动） | 点声音卡“夜深人静”/“小声聊天”/“广场舞音乐”，广场上的人、监测屏数字和“监测器透视”三格（输入—计算—输出）同步变化，超标时屏幕泛红 | 三张卡：输入/计算/输出各是什么数据；迁移：电热水壶 |
| 2 声音记录亭（波形与散点） | 点红色录音键录10秒，同时左右拖动音量推杆（或选教师现场/本机麦克风）；录完在两个圆点之间点一下读数 | 曲线为何更合适、散点代表什么；迁移：气温读中间值 |
| 3 3号楼小明家（生活中的连续量） | 拖动窗帘把手看光照表与曲线（≥8个不同读数）；开始烧水，在途中“读水温” | 7张数据卡逐张判断是否连续量；迁移：车速表 |
| 4 物业控制室（阈值） | 回放同一晚噪声曲线；红线就是阈值，可拖滑块或直接在图上拖红线；先55 dB运行，再换明显不同的阈值运行，报警灯随回放闪烁 | 阈值在哪个环节、为何次数变；4张案例卡找阈值 |
| 5 屋顶种植园（迁移设计） | 依次选①传感器测什么 ②何时开水泵 ③阈值（未选好前不出现下一步，不预先替学生选），运行4天；植物叶片随湿度变蔫/变绿 | 阈值作用、阈值调高的后果；迁移：鱼缸加热棒 |

判定规则、证据要求、服务端复算、积分去重与第一版完全相同（`rules.js` 未改）；只换了学生端的呈现与引导。每站10积分，同一轮只记一次；错误不扣分。地图上未完成前一站时后一站上锁；“巡查报告站”随时可进，但五站完成后才高亮。菜单（☰）里有“本站实验记录”“再看一次本站情境”“本站重新做实验”“切换学生”。

素材与许可见 `docs/素材来源.md`（Kenney Toon Characters 与 Interface Sounds，CC0；其余为原创SVG）。`public/` 全部约 0.5 MB，离线可用；角色姿势图用到时才加载，音效首次播放时才加载。

20题考核与通关积分分开：40题库按5项目标各8题，每次每目标抽4题、选项顺序打乱。提交前可改答案、页面列出未答题号且不显示对错；提交后错题在前，逐题显示自己的选择、正确答案和解析。可“再考一次 · 新抽20题”，服务端保留每次成绩（教师端显示首次和最近）。考后选做“阈值调校挑战”（5个需求→拖动阈值，不计分）。

## 现场数据与仿真边界

- 第1、3、4、5关和第2关的“模拟推杆”都是教学仿真数据，图上标注“仿真”。噪声单位 dB 只用于仿真。
- 麦克风只计算相对响度（0—100），不是分贝，不录音、不上传音频。第2关可选“观察教师现场”（读取教师大屏广播的现场响度）或“本机麦克风”。
- 教师大屏底部“全班一起观察：教室噪声监测”（教材拓展与提升）：开启教师机麦克风，拖动现场阈值，超过阈值时提示并计数；局域网HTTP页面会弹出 localhost 授权小窗（与第4课相同方式），需允许弹窗。

## 教师大屏与隔离测试

显示名单人数、已进入、未进入、完成主线、已考核；全班状态、五关完成（分母为本班名单+手动加入）、提交解释后“首次符合/最近符合”（未提交单列，不计作错误；无数据显示“尚无证据”）、考核按目标首次/最近正确率、常见错误与建议、学生明细与具体证据。每5秒刷新。

“进入教师测试模式”（`/test`）用虚构身份自由选站（地图上所有地点都可进入，顶部黄色工具条），可看本关标准操作与答案、载入达标示例、查看40题答案、试做20题测试卷、直接试玩考后挑战；全部只存在本页，不写入班级数据。`/demo` 是无身份演示，同样不保存。“开启本班新轮次”保留旧轮记录，新轮重新计进度与积分，旧轮待同步记录不会覆盖新轮。教师可“导出班级记录”（JSON）。学生端不设额外的导出模块。

## 保存、备份与迁移

课堂数据在 `runtime/classroom.sqlite`。服务重启后保留进度、首次预测、首次/最近提交与考核历史。断网时记录先存本机（按身份和轮次隔离），恢复后自动补传并去重；状态栏显示“未同步”时尚未进入大屏。备份：先停止服务，再复制整个 `runtime/`。迁移：复制整个应用目录（含私有 `roster.json` 与备份），安装 Node 22.13+ 后 `npm start`。

名单：`roster.json` 已从六年级名单导入 314 人（601—606），ID 规则与第4课相同（同一学生在两课的 ID 一致）。`roster.json` 与 `runtime/` 不在 public 目录、学生网页无法下载，并已列入 .gitignore；公开示例用 `roster.example.json`（虚构姓名）。更新名单：`python3 tools/import-roster.py /路径/六年级班级姓名名单.xlsx`（需 openpyxl）。
