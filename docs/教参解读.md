## 三、蓝栏要点（备课抓手）
1. **情境与责任**：居民区噪声是社会问题；补充公园、博物馆等场所的监测器。
2. **导入三步**：回顾IPO → 画噪声监测系统示意图 → 问“流动的要素是什么”→ 聚焦“数据”。
3. **活动1两步**：先自主发现“采集声音数据”；再**凭第一感觉**判断波形图 / 散点图；教师**简单讲**连续量概念并明确“声音是连续量”。
4. **连续性多举例**：温度、水位、声音、生长期身高、烧水水温。
5. **活动2**：提供计量仪表（水表、温度计、车速表）直观感受；观察上课铃声、接水水面、阳光时强时弱。
6. **阈值是难点**：不强调概念，强调**作用**；只要求初步了解；为第五单元种植园做铺垫（本课不提前做种植园）。
7. **拓展**：数据标准（跳绳、跑步评分标准）；无噪声监测器时用**虚拟仿真噪声监测系统**做“定教室阈值”。

## 四、逆向设计

### 阶段一：预期结果（只用教参的3条目标 + 2项重难点）
- 目标1：了解控制系统工作时产生的数据（输入、计算、输出都有数据，数据≠装置）。
- 目标2【重点：连续量数据的表现形式】：知道声音等连续量用连续的波形 / 曲线表示更合适（任意两时刻之间都有数值）；能在生活中识别连续量。
- 目标3【难点：阈值的含义与作用】：能说出阈值是与数据比较、决定系统是否动作的参考值；阈值改变，判断结果随之改变；阈值可参考标准、按需求设定。

### 阶段二：可接受的证据
| 目标 / 重难点 | 表现性证据（应用内） | 其他证据 |
|---|---|---|
| 目标1 | 画对示意图（放错可重放，记录首次）；指出“计算格出现 {自己测到的dB} > 55 → 超标”；输入 / 计算 / 输出各选出流动的数据；迁移：电热水壶 / 智能路灯中选“数据→比较结果→指令” | 导入第6—7屏口答；20题中6题 |
| 目标2·重点 | 先凭第一感觉选图（记首次）；在两个散点之间点读出中间值并据此解释；说出采集的是声音数据；拉窗帘≥8个读数；吹纸片关系卡；仪表卡；7张校园数据卡分类；迁移：估中间值、判断是否经过中间值 | 吹纸片全班动手；20题中7题 |
| 目标3·难点 | 同一晚数据换阈值运行两次并解释次数变化；阈值的作用卡；阈值在哪个环节；教材案例2—5找阈值（4张）；迁移：自动门 / 空调改阈值；第5站：参考标准与同学可接受音量定教室阈值，只在喧哗时提示（服务端复算），解释为什么不照搬55 dB、阈值的作用、调高到80 dB的后果，迁移到跳绳 / 跑步评分标准 | 全班商定班级阈值；20题中7题（另含考后小游戏阈值关） |

### 阶段三：学习活动（顺序与教材一致）
导入（情境→回顾IPO→画示意图→流动的要素）→ 第1站（目标1）→ 第2站 学习活动1（重点）→ 第3站 学习活动2（重点）→ 第4站 学习活动3（难点）→ 第5站 拓展与提升（难点·应用）→ 总结 →（下一课开头）20题考核 →（≥80分）奖励小游戏。
