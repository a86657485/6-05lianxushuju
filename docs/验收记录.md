| 视口 / 模式 | 检查步数 | 每步恰好1个主要操作 | 在视口内且未被遮挡 | 控制台/页面错误 | 结束积分 |
|---|---|---|---|---|---|
| 1366×768 学生（登录→五站→20题→教师大屏→测试模式） | 95 | 95/95 | 95/95 | 0 | 50（服务端50，考核记录1次） |
| 1920×1080 学生（同上） | 95 | 95/95 | 95/95 | 0 | 50（服务端50，考核记录1次） |
| 390×844 手机竖屏（演示模式，五站） | 82 | 82/82 | 82/82 | 0 | 50 |
| 1366×768 减少动态效果（演示模式，五站） | 82 | 82/82 | 82/82 | 0 | 50 |

走查覆盖：班级→姓名→同名确认；每站“想一想→做实验→说清楚”；第1、3、4站故意答错一张卡，检查标红卡片被点亮、改正后通过；第1、3、4站点 **?** 求助，聚光灯照亮当前操作；第5站先用60%失败、再用35%达标；五站完成后地图高亮“巡查报告站”，完成20题（含翻页、提交）并看到成绩与错题解析；随后打开教师大屏（看到该学生记录）和教师测试模式（地图6个地点全部可进）。

走查中发现并已修复：求助提示框挡住选项文字（改为按遮挡面积选位置，宽元素优先放侧边）；手机上演示工具条挡住底部引导栏（手机隐藏）；手机上目标控件被吸底引导栏盖住时不会自动滚动（滚动判断扣除引导栏高度）；地图上角色挡住地点图标（右移）。
