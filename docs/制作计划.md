# 第5课《连续变化的数据》应用制作计划

## 依据
- 教参《第5课 连续变化的数据》（3页）：目标、重难点、三个活动、拓展与提升；教参提示“重在阈值的作用，而非概念”，为第五单元种植园监测打基础。
- 课本PPT（21页）：噪声监测数据、波形图与散点图、窗帘/吹纸片/水表/温度计/车速表、55 dB 等阈值案例、噪声标准（30—40 dB 安静、55 dB 以上干扰、90 dB 以上危害）。
- 第4课“校园系统探索站”的结构与约定（端口、登录、三步关卡、积分、考核、教师大屏、测试模式、离线队列、麦克风桥）。
- 技能“备课玩中学交互应用”的课堂反馈与需求清单。

## 范围与取舍
| 项 | 决定 | 理由 |
|---|---|---|
| 主线 | 5关：数据流动 → 波形与散点 → 生活连续量 → 阈值 → 种植园迁移 | 对应教参活动1—3和拓展，最后一关衔接第五单元 |
| 情境 | 小区夜间噪声监测贯穿第1、2、4关 | 教材原情境；同一数据串起“数据—连续量—阈值” |
| 呈现 | 2D SVG 场景与曲线 | 曲线读数是本课核心，2D 更清楚；省去3D依赖 |
| 角色 | 沿用第4课小递（SVG） | 单元一致 |
| 麦克风 | 复用第4课相对响度与 localhost 授权窗 | 已在第4课验证过的方式；明确“不是分贝” |
| 仿真 | 所有曲线可复现（确定性函数），并标注“仿真” | 规则可测试，教师可预知结果 |
| 考核 | 40题 = 5目标 × 8，每次每目标抽4题，选项打乱 | 技能要求每次20题、可重考 |
| 导出 | 只保留教师班级导出，学生端不设导出 | 技能要求避免额外学生导出模块 |

## 关键数据设计（已用测试锁定）
- 第1关：安静场景约38 dB、聊天约49 dB、广场舞约66 dB；判定“超过55 dB”。
- 第4关：同一晚181个分钟读数，提示次数随阈值变化：40→5、45→6、50→4、55→3、60→2、65→1、70→0（相隔3分钟以内的超标合并为一次提示）。说明：阈值在40与45之间出现“降低阈值反而提示次数变少”是因为连续超标被合并，教师可借此讨论“提示次数”与“超标时长”的区别。
- 第5关：4天、每半小时一步；穷举验证只有“土壤湿度 + 降到阈值及以下开泵 + 阈值30—45%”能让湿度保持在30%—70%；光照、温度方案在阴天会失败，促使学生选“直接反映需求的数据”。

## 制作顺序
1. 规则与仿真（rules.js）→ 题库（quiz.cjs）→ 服务端（server.cjs、teacher-access.cjs）
2. 学生端：登录、三步关卡、实验、解释、提示、考核、考后挑战
3. 教师端：大屏统计与图表、诊断、明细、现场噪声监测、测试模式
4. 自动化测试 → 启动服务 → 无头浏览器走查与截图 → 文档
