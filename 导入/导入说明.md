# 第5课《连续变化的数据》导入页 · 使用说明与讲稿

**打开方式**：双击 `导入.html`（或 `index.html`），建议用 Chrome / Edge。完全离线，不需要网络、不需要启动课堂服务；整个“导入”文件夹可以直接拷到机房电脑或U盘（共约1.6 MB，不含截图）。
**时长**：约4分钟（第6屏“教室有多响”为选做，时间紧可直接跳过）。
**目的**：从第4课“输入—计算—输出”出发，引出“系统中一直在流动的是数据”；用小区噪声监测情境激发对“数据怎样变化”“系统凭什么判断该提醒”的好奇，**不揭示**连续量、波形/散点、阈值的结论（留给数据站第2、4关）。

## 操作

| 按键 / 操作 | 作用 |
|---|---|
| → / 空格 / PageDown / Enter（翻页笔下一页） | 下一步（同一屏内先逐条出现，再进入下一屏） |
| ← / PageUp（翻页笔上一页） | 上一步 |
| F 或右下“全屏” | 全屏 / 退出全屏 |
| 1—8 / Home / End | 跳到第几屏 / 首屏 / 末屏 |
| P（或点击视频） | 视频播放 / 暂停；R 重播 |
| A / B（或点卡片） | 第7屏投票计数 |
| . | 黑屏，再按任意键恢复 |
| ? | 显示快捷键 |

鼠标静止约3秒后，底部控制栏和鼠标指针会自动隐藏。控制栏右侧有导入计时，超过4分钟会变成红色。画面按16:9等比缩放，1920×1080 和 1366×768 均已测试。

## 逐屏讲稿与提问

| 屏 | 画面 | 讲稿 / 提问（建议） | 时间 |
|---|---|---|---|
| 1 封面 | 发光的声音曲线 + 小递挥手；“数据一直在变，系统怎样知道该做什么？” | “同学们好，今天小递带我们去一个地方。先记住这个问题——数据一直在变，系统怎样知道该做什么？” | 10秒 |
| 2 回顾：声控灯 | 输入（采集声音）→ 计算（判断有没有声音）→ 输出（灯亮/灯灭）。按一下：箭头上出现流动的光点和“？”；再按一下：揭示“数据” | “上节课的声控灯，三个环节分别做了什么？”（学生答）按键：“看，三个环节之间一直有东西在‘流动’，它是什么？”（学生猜）按键揭示：“对，是**数据**。声音变成数据，数据被计算，计算结果变成动作。今天我们就来研究这些数据。” | 40秒 |
| 3 夜晚的小区 | 夜晚小区广场舞插图，噪声屏显示“??.?”；按一下：楼上写作业的同学捂耳朵 | “晚上8点半，广场上的音乐响起来了。”按键：“可楼上的同学正在写作业……到底有多吵？只靠耳朵感觉，说得清吗？”（引出“要用数据说话”） | 30秒 |
| 4 视频：噪声显示屏 | 22秒视频（有声音）：音乐越来越响，显示屏数字一点点往上爬，曲线在画，越过红色虚线后弹出“噪声提醒”，最后问“屏幕是怎么知道‘该提醒了’？”。按一下：右侧出现三个问题（视频播完也会自动出现） | 先不说话，让学生看完。然后指着问题：“① 数字是怎样变化的？是一下子跳上去，还是……？② 那条红色虚线可能是什么？③ 屏幕凭什么判断该提醒了？”**只收集猜想，不评对错**：“这三个问题，今天的数据站里都能找到答案。” | 50秒 |
| 5 生活中的显示屏 | 公园、博物馆、马路边三块显示屏插图，下方数字和小曲线在实时跳动（仿真）；按一下出现提问 | “这样的屏幕你在哪里见过？”（学生举例）按键：“盯着这些数字看——它们会停下来吗？两个数字之间，还有别的数吗？”（埋下连续量的伏笔，不下结论） | 25秒 |
| 6 教室有多响（选做） | 大号读数 + 最近15秒曲线。“开启麦克风”用教师电脑麦克风；没有麦克风时按住“模拟声音” | “我们教室现在有多‘响’？”开启麦克风。“安静挑战：全班安静5秒，看曲线能降到哪里。”再请一位同学轻轻拍一下手，看曲线怎样变。**提醒：这个数是相对响度，不是分贝。**不需要全班喊叫。 | 40秒（选做） |
| 7 猜一猜 | A 连续起伏的曲线 / B 一个个分开的点 | “声音数据，用哪种图表示更合适？举手投票！”老师点卡片或按A/B计数。“答案藏在今天的第2站，看看谁猜对了。”（**不公布答案**） | 30秒 |
| 8 带着问题出发 | 三个问题 + 数据站网址 + 小递 | “今天，我们带着三个问题出发：数据怎样流动？声音数据长什么样？系统凭什么判断该提醒了？打开噪声监测数据站，先选班级、再选自己的名字。” | 15秒 |

> 第8屏的网址可以直接点击修改为终端显示的地址（如 `http://192.168.1.23:8796/`），按回车保存，以后打开会记住（只存在这台电脑的浏览器里）。

## 与教案的对应
对应教案“一、情境导入（4分钟）”。导入只提问、不下结论：“数据”这个答案在第2屏揭示（衔接第4课），连续量、波形与散点、阈值的结论都留给数据站的第2—4关。视频中的红色虚线只标“？”，没有出现“阈值”二字。

## 素材来源与许可
- **全部图片**（封面声波、夜晚小区广场、楼上写作业的同学、公园/博物馆/马路边显示屏）：为本课原创的矢量插画，用代码绘制（SVG，Noto Sans CJK 字体）后由无头浏览器导出为 JPG；小递造型与第4、5课应用一致。没有使用AI生成图片，也没有使用网络图片或真实照片。
- **视频** `assets/video/noise-screen.mp4`：原创动画，用同一套插画逐帧渲染（1280×720，25帧/秒，550帧），配乐为代码合成的五声音阶旋律与鼓点（音量随画面中的噪声数值一起变大），提醒音为合成蜂鸣；用 ffmpeg 编码为 H.264 Main + AAC，时长22秒，约0.99 MB。画面中的 dB 数值为教学仿真，不是真实测量。
- **字体**：页面使用电脑自带字体（苹方 / 微软雅黑），没有打包字体文件。
- 以上素材均为本课自制，可在教学中自由使用、修改。`素材源文件/` 中保留了生成脚本，需要时可以改了重新生成。

## 已知限制
- 第6屏的麦克风读数是浏览器计算的相对响度（0—100），不是分贝；不同电脑、麦克风之间不能直接比较。双击打开（file://）时，Chrome/Edge 会弹窗询问麦克风权限，点“允许”即可；拒绝或没有麦克风时会提示改用“模拟声音”。
- 视频有声音，请先调好教室音箱音量。用键盘或翻页笔进入第4屏会自动有声播放；如果浏览器拦截了有声自动播放，会先静音播放，并在视频下方显示“🔇 点我开声音”，点一下视频即可打开声音。
- 只在 Chromium/Chrome 测试过，没有测 Safari、360 浏览器和学校的旧版浏览器。
